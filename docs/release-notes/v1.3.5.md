# v1.3.5

修复 Agent 慢命令轮询、Windows WSL 文件列表，以及全会话断线后的按键重连体验。

## 变更摘要

| 项 | 说明 |
| --- | --- |
| 修复 | Agent 长任务等待：不再因短暂无输出提前结束 `wait_ms`，避免连环 `terminal_tail` |
| 修复 | Windows WSL 文件列表为空（`wsl.exe` 改用 `--exec`，避免 `$var` 被二次解析吃空） |
| 优化 | 会话断开：SSH / 本地 / WSL / Agent 下栏均可按任意键重连；取消弹窗后仍可继续 |
| 优化 | Agent 环路：`terminal_tail` 仅靠加大 `wait_ms` 不再绕过重复调用检测 |

## 详细说明

### Agent 慢命令等待

此前 `wait_ms` 虽阻塞，但输出安静约 1.5s 即 `quiet_settled` 提前返回，`sleep` / `docker pull` 等会触发反复轮询。现长等待（≥5s）仅在 **shell 提示符 / 错误静默 / 截止** 时结束；`wait_ms` 支持字符串数值；提示词与工具描述同步为「一次给足 wait」。

### WSL 文件列表

`wsl.exe -d Distro -- sh -lc` 经发行版默认 shell 再解析，列表脚本中的 `$p` 等变量为空，面板只显示 `..`。已改为 `--exec sh -lc`。

### 断线重连

- 断线仍可弹一次确认；取消后终端提示「按任意键重新连接」
- 主标签与 Agent 下栏统一支持按键 / 右键直接重连
- 标题栏右键在已断线时可直接重连
