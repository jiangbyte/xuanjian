# v1.3.7

Docker 面板与进程树增强，主机清单支持本地 Shell，并修复 Ping 与文件浏览体验。

## 变更摘要

| 项 | 说明 |
| --- | --- |
| 优化 | Docker：Compose 项目分组与展开/折叠；停止后再删除（不再 `docker rm -f`）；确认对话框按钮文案修正 |
| 新增 | 进程面板：可视化进程树，支持搜索、展开/折叠，单节点 TERM / KILL |
| 优化 | Ping：次数留空表示无限 ping |
| 优化 | 文件浏览：默认显示隐藏文件 |
| 新增 | 主机清单：本地 Shell 独立分组；新建主机弹窗支持 SSH / 本地 Shell 双 Tab；批量操作栏始终可见（本地 Shell 分组下禁用） |

## 详细说明

### Docker 面板

- Compose 容器按项目分组，可展开/折叠查看
- 删除运行中容器时先停止再 `docker rm`，避免 `-f` 强制删除
- 确认对话框按操作显示正确按钮文案（停止 / 删除等）

### 进程树

- 由 PPID 构建可视化进程树，替代纯文本 `pstree` 输出
- 支持搜索过滤、节点展开/折叠
- 每个进程节点可单独发送 TERM 或 KILL 信号

### 主机清单 · 本地 Shell

- 侧栏新增「本地 Shell」分组，与 SSH 主机分开展示
- 「全部分组」仅显示 SSH 主机；本地 Shell 在专属分组中管理
- 新建主机弹窗：Tab 1 为 SSH 表单，Tab 2 为本地 Shell；弹窗固定高度，切换 Tab 不抖动
- 批量操作栏始终显示；在本地 Shell 分组下禁用并提示不支持批量操作

### 其他

- Ping 次数输入框留空时，改为无限 ping（此前误默认为 4 次）
- SFTP / 侧栏文件浏览默认显示以 `.` 开头的隐藏文件

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `*_x64-setup.exe`（NSIS）、`*_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` `.dmg` / `.app` |
| macOS Intel | `x64` `.dmg` / `.app` |
| Linux x64 | `.deb`、`.AppImage`、`.rpm` |

安装包不含用户数据；首次运行在本机创建空库。Windows 需 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
