## 亮点

### 产品精简

- 移除移动端伴侣 / Android APK 产品线（桌面安装包流程不变）
- 移除 Docker Compose / Dockerfile **编排工作室**（`/docker`）
- **保留**终端侧栏 Docker 面板与 Agent `docker_*` 工具
- 数据库迁移 v28：删除 `docker_projects` 表

### 相对 v1.3.1

性能与构建修复见 [v1.3.1](./v1.3.1.md)。

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `*_x64-setup.exe`（NSIS）、`*_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` `.dmg` / `.app` |
| macOS Intel | `x64` `.dmg` / `.app` |
| Linux x64 | `.deb`、`.AppImage`、`.rpm` |

安装包不含用户数据；首次运行在本机创建空库。Windows 需 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
