## Highlights

### v1.0 — 运维全量能力

- **MCP 运行时**：设置中配置 HTTP / stdio MCP 服务器，测试连接，Agent 启动时自动发现外部工具并合并进工具注册表
- **审计控制台**：侧栏 `/audit` 可筛选 Agent 工具执行、SSH 连接、批量、部署、告警等本地审计事件
- **增强导出（v2 格式）**：备份 JSON 可包含工作空间、告警规则、审计摘要；可选使用本机 `encrypt_secret` 加密整包
- **连通性与 Agent 扩展**（M1–M5）：跳板机 / known_hosts / SSH 代理、文件·网络·Docker 只读工具、工作空间与部署、批量与定时任务、告警、机群概览与指标快照

### 核心能力（延续）

- **玄鉴 Agent**：本地 ReAct 编排 + SubAgent（巡检 / 终端 / 网络 / Docker / 部署 / 分析）
- **模型与协议**：OpenAI 兼容与 Anthropic Messages；MCP 元数据配置
- **终端工作区**：本地 / SSH / WSL、SFTP、侧栏巡检、会话录制

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `Xuanjian_1.0.0_x64-setup.exe`（NSIS，推荐）、`Xuanjian_1.0.0_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` 的 `.dmg` / `.app` 包 |
| macOS Intel | `x64` 的 `.dmg` / `.app` 包 |
| Linux x64 | `Xuanjian_1.0.0_amd64.deb`、`Xuanjian_1.0.0_amd64.AppImage`、`Xuanjian-1.0.0-1.x86_64.rpm` |

安装包不含本机用户数据；首次运行会在本机创建空库。

Windows 需已安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（系统通常已自带）。

## 升级说明

从 `v0.1.x` 升级可直接安装覆盖；本地 SQLite / 配置仍保留在本机 AppData（或对应平台数据目录）。

导出格式升至 **v2**：新增 `workspaces`、`alertRules`、`auditSummary` 字段；仍兼容 v1 导入。

加密导出包使用与本机口令相同的 AES 密钥，**仅可在同一台设备上解密**。
