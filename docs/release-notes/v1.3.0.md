# v1.3.0

## 亮点

### Agent 下栏终端

- 终端工作区上下分屏：用户主终端 + **Agent 下栏终端**（独立 PTY、多标签）
- `terminal_run` / `session_exec` 在下栏可见执行，不再静默绕过
- Agent 会话输出录制、transcript 回放与 UI 同步
- `terminal_tail` 读取下栏会话，与执行面一致

### 终端与侧栏

- 侧栏列表紧凑化（Docker / 端口 / 进程 / 脚本等）
- Docker 日志：文本可选中复制、自动跟随最新、暂停跟随时可「回到底部」
- SFTP 工具栏窄屏横向滚动；下栏收起不再卸载主终端 xterm

### Agent 与 UI

- LangGraph 运行时（`agent-core` / `agent-adapters`）持续加固
- AI 侧栏 ReAct 卡片换行优化，避免超长水平滚动
- 设置页重组：Agent 目录、插件/工具、MCP 分区

### 网络工具

- 连接列表、流量监控、测速图表等面板扩展

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `*_x64-setup.exe`（NSIS）、`*_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` `.dmg` / `.app` |
| macOS Intel | `x64` `.dmg` / `.app` |
| Linux x64 | `.deb`、`.AppImage`、`.rpm` |

安装包不含用户数据；首次运行在本机创建空库。Windows 需 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
