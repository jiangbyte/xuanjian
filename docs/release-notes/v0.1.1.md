## Highlights

- 定位为 **AI 桌面运维工作台**：主机、终端、脚本、网络、Docker 与内置 Agent 一体
- **玄鉴 Agent**：本地 ReAct 编排 + SubAgent（巡检 / 终端执行 / 分析）
  - 可读脚本库（`list_scripts` / `get_script`）与历史命令（`list_cmd_history`）
  - `run_script` / `terminal_run` 写入可见终端；计划 / 确认执行 / 完全执行权限模式
  - 待确认操作固定展示在输入区上方，避免藏在折叠子轨迹中
- **模型与协议**
  - 自定义供应商与模型（上下文窗口、最大输出 Token、思考强度）
  - OpenAI 兼容 → `{base}/v1/chat/completions`；Anthropic Messages → `{base}/v1/messages`
  - 按文档填写 Base URL，不做供应商路径特例改写
- **体验**
  - 设置改为独立页面；模型 / MCP / Agent 分区配置
  - Agent 会话在切笔记轨、离开终端页后可恢复
  - Markdown 计划项正确渲染；聊天区紧凑排版

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `Xuanjian_0.1.1_x64-setup.exe`（NSIS，推荐）、`Xuanjian_0.1.1_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` 的 `.dmg` / `.app` 包（构建完成后见资产列表） |
| macOS Intel | `x64` 的 `.dmg` / `.app` 包（构建完成后见资产列表） |
| Linux x64 | `Xuanjian_0.1.1_amd64.deb`、`Xuanjian_0.1.1_amd64.AppImage`、`Xuanjian-0.1.1-1.x86_64.rpm` |

安装包不含本机用户数据；首次运行会在本机创建空库。

Windows 需已安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（系统通常已自带）。

## 升级说明

从 `v0.1.0` 升级可直接安装覆盖；本地 SQLite / 配置仍保留在本机 AppData（或对应平台数据目录）。
