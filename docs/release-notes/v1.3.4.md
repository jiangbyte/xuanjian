# v1.3.4

终端侧栏 / 日志 / 批量上传与主机清单的体验优化。

## 变更摘要

| 项 | 说明 |
| --- | --- |
| 优化 | 终端左侧栏：切换 tab 后保留面板状态（keep-alive，不卸载） |
| 优化 | Docker 日志：支持全屏、换行开关 |
| 优化 | 批量文件传输：先入队再传输；文件夹可按组控制进度 |
| 优化 | 主机清单：名称与连接串支持点击 / 右键复制 |

## 详细说明

### 终端左侧栏状态保留

切换文件、脚本、历史、概览、进程、端口、Docker 等侧栏 tab 时，已访问过的面板会隐藏而非卸载。当前目录、Docker 选中项、日志窗口等可在切回后继续使用。概览在非激活时暂停轮询。

### Docker 日志查看

日志浮动窗口增加：

- **全屏**切换
- **换行**开关（默认开启）

### 批量上传 / 传输队列

上传文件夹或多文件时，会先完成冲突处理并收集任务，再一次性加入传输队列，避免「传一个显示一个」。同属一个文件夹（或一批散文件）的任务在传输面板中分组展示，支持组级进度与暂停 / 继续 / 取消。

### 主机清单复制

主机列表中的**名称**与**连接串**（`user@host:port`）可点击复制，也可通过右键菜单复制；点击行空白处仍会连接。

## 相对 v1.3.3

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `*_x64-setup.exe`（NSIS）、`*_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` `.dmg` / `.app` |
| macOS Intel | `x64` `.dmg` / `.app` |
| Linux x64 | `.deb`、`.AppImage`、`.rpm` |

安装包不含用户数据；首次运行在本机创建空库。Windows 需 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
