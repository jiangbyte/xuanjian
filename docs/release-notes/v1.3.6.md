# v1.3.6

修复浮动窗被终端盖住，并支持终端 BEL 响铃反馈。

## 变更摘要

| 项 | 说明 |
| --- | --- |
| 修复 | 文件编辑等浮动窗 Portal 到 `body`，不再被 xterm 画布穿层盖住 |
| 优化 | 终端 BEL：默认视觉闪烁；设置中可选轻提示音 / 闪烁+音 / 关闭 |

## 详细说明

### 浮动窗层级

`FloatingWindow` 原先挂在侧栏 Resizable 树内，`position: fixed` 受层叠上下文限制，中间终端画布会盖住编辑器内容。现通过 Portal 挂到 `document.body`，与 Dialog 一致始终置顶。

### 终端响铃

xterm.js 5+ 不再内置响铃。现订阅 `onBell`：默认边框闪烁；设置 → 终端 → 响铃 可选关闭、视觉、轻提示音或两者。连续响铃有节流。

## 相对 v1.3.5

Agent 长等待、WSL 文件列表、断线按键重连见 [v1.3.5](./v1.3.5.md)。

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `*_x64-setup.exe`（NSIS）、`*_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` `.dmg` / `.app` |
| macOS Intel | `x64` `.dmg` / `.app` |
| Linux x64 | `.deb`、`.AppImage`、`.rpm` |

安装包不含用户数据；首次运行在本机创建空库。Windows 需 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
