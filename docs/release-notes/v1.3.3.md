# v1.3.3

修复终端粘贴多行命令时行续接失效的问题。

## 变更摘要

| 项 | 说明 |
| --- | --- |
| 修复 | 终端粘贴：Windows CRLF（`\r\n`）导致 bash `\` 续行被拆成多条命令 |
| 范围 | 快捷键粘贴、右键粘贴、DOM paste；脚本投递路径一并规范为 LF |

## 详细说明

### 终端多行粘贴 / 行续接

从 Windows 剪贴板粘贴带 `\` 续行的命令（例如多行 `docker run`）时，实际写入 PTY 的是 `\<CR><LF>`。bash 中 `\` 只转义紧随的 `\r`，随后的 `\n` 仍会结束当前命令，下一行 `--name` 等参数会被当成新命令（`command not found`）。

本版在写入会话前将粘贴文本统一规范为 LF（`\r\n` / 孤立 `\r` → `\n`），与脚本「投递到终端」路径行为一致。
