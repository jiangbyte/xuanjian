# v1.3.1

## 亮点

### 性能

- Hosts / Scripts：修复 `reload` 依赖不稳定导致的重复查询；列表加载改为 `Promise.all`
- 批量删除并行化（Hosts / Scripts / Notes / Docker）
- 终端工作区懒挂载 + 首帧后全力预热（Monaco / xterm / 图表 / 侧栏），多标签状态完整保留
- Scripts 编辑器、终端左侧 pane、AI `runAgentTurn` 懒拆包，配合预加载秒开
- AI 消息 `memo`、纯文本轻量渲染；SFTP / 进程 / AI 消息列表虚拟化
- Vite 拆出独立 `echarts` chunk

### 构建 / CI

- 修复生产构建失败：`agent-loop-guard`（`node:crypto` / `node:util`）替换为浏览器兼容实现
- 前端 CI `pnpm build` 可通过

## 安装包

| 平台 | 产物 |
| --- | --- |
| Windows x64 | `*_x64-setup.exe`（NSIS）、`*_x64_en-US.msi` |
| macOS Apple Silicon | `aarch64` `.dmg` / `.app` |
| macOS Intel | `x64` `.dmg` / `.app` |
| Linux x64 | `.deb`、`.AppImage`、`.rpm` |

安装包不含用户数据；首次运行在本机创建空库。Windows 需 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
